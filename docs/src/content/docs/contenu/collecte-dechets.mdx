La collecte des déchets vous permet de publier les plannings de ramassage sur le site de votre commune. Les citoyens peuvent ainsi consulter les jours de collecte selon le type de déchet et leur zone. Cette page vous guide dans la configuration de ces plannings.

## Liste des plannings

Les plannings de collecte sont affichés dans une liste verticale. Chaque ligne présente :

- Un **cercle coloré** avec une icône de recyclage, dont la couleur correspond au type de déchet
- Le **type de déchet** (nom)
- Un **badge du jour** de collecte (coloré)
- Un **badge de fréquence** (contour)
- Le **statut** : Actif (vert) ou Inactif (gris)
- La **zone** (si renseignée)
- Les **notes** complémentaires (si renseignées, tronquées)

:::note[Bon à savoir]
Les plannings inactifs sont affichés avec une opacité réduite. Ils ne sont pas visibles sur le site public.
:::

### Types de déchets

Cinq types de déchets sont disponibles, chacun avec sa couleur :

- **Ordures ménagères** (gris) — Déchets non recyclables du quotidien
- **Tri sélectif** (jaune) — Emballages, papiers et cartons recyclables
- **Verre** (vert) — Bouteilles, bocaux et flacons en verre
- **Déchets verts** (émeraude) — Tontes, tailles, feuilles mortes
- **Encombrants** (violet) — Meubles, électroménager, objets volumineux

### Fréquences de collecte

- **Hebdomadaire** — Chaque semaine, le même jour
- **Bimensuel** — Une semaine sur deux
- **Mensuel** — Une fois par mois

## Créer un planning

1. Cliquez sur le bouton **Nouveau planning** en haut de la liste
2. Remplissez le formulaire (voir les sections ci-dessous)
3. Cliquez sur **Créer**

### Type de collecte

- **Type de déchet** (obligatoire) — Sélectionnez parmi les cinq types disponibles
- **Jour de collecte** (obligatoire) — Lundi, Mardi, Mercredi, Jeudi, Vendredi, Samedi ou Dimanche
- **Fréquence** (obligatoire) — Hebdomadaire, Bimensuel ou Mensuel

### Planification

- **Date de début** — Date de référence pour le calcul des collectes. Son utilité varie selon la fréquence :
  - **Hebdomadaire** : optionnel
  - **Bimensuel** : permet de déterminer les semaines paires/impaires de collecte
  - **Mensuel** : permet de déterminer quelle semaine du mois la collecte a lieu

### Zone et notes

- **Zone** — Nom de la zone géographique (100 caractères max., ex : "Centre-ville", "Quartier Nord"). Permet de distinguer les zones si les jours de collecte diffèrent selon les quartiers.
- **Notes** — Informations complémentaires (500 caractères max.)

### Statut

- **Actif** — Cochez pour rendre le planning visible sur le site public. Activé par défaut.

:::tip[Astuce]
Si votre commune a plusieurs zones avec des jours de collecte différents, créez un planning par zone et par type de déchet. Le champ **Zone** permet aux citoyens de retrouver facilement leur planning.
:::

## Modifier un planning

Depuis la liste, cliquez sur le bouton **Modifier** (icône crayon) du planning souhaité.

Le formulaire s'affiche avec les données existantes. Effectuez vos modifications, puis cliquez sur **Modifier**.

## Activer et désactiver

Depuis la liste, cliquez sur le bouton **Activer** / **Désactiver** (icône marche/arrêt) pour basculer la visibilité du planning sur le site public.

:::tip[Rappel]
Les changements de visibilité ne sont effectifs sur votre site qu'après un [déploiement](/administration/deploiement/).
:::

## Supprimer un planning

Depuis la liste, cliquez sur le bouton **Supprimer** (icône corbeille).

Un dialogue de confirmation s'affiche. Cliquez sur **Supprimer** pour confirmer ou **Annuler** pour revenir en arrière.

:::caution[Attention]
La suppression est définitive.
:::
