L'éditeur de texte riche est l'outil principal pour rédiger du contenu dans Communeo. Il existe en deux variantes : une version compacte pour les champs courts et une version complète pour les pages, actualités et événements.

## Les deux variantes

| Caractéristique | Compacte | Complète |
|-----------------|----------|----------|
| Hauteur | 120 px | 300 px et plus |
| Mise en forme de base | Gras, Italique, Souligné, Titres, Listes, Lien | Toutes les options de base |
| Mise en forme avancée | — | Exposant, Indice, Alignement, Couleur, Typographie |
| Médias | — | Images, Vidéos, Tableaux |
| Blocs et modèles | — | Encart info, Citation, CTA, Modèles, Blocs réutilisables |
| Sauvegarde automatique | — | Brouillon local toutes les 30 secondes |
| Compteur de mots | — | Mots et caractères |
| Menu contextuel de sélection | — | Gras, Italique, Souligné, Lien |

:::note[Bon à savoir]
L'éditeur s'adapte automatiquement selon le contexte : les champs de description courte utilisent la variante compacte, les champs de contenu principal utilisent la variante complète.
:::

## Barre d'outils

La barre d'outils regroupe l'ensemble des boutons de mise en forme. En variante complète, vous disposez également des boutons **Annuler** et **Rétablir** pour naviguer dans l'historique de vos modifications.

### Mise en forme du texte

- **Gras** — Met le texte en gras (raccourci : Ctrl+B)
- **Italique** — Met le texte en italique (raccourci : Ctrl+I)
- **Souligné** — Souligne le texte (raccourci : Ctrl+U)
- **Exposant** — Place le texte en exposant (ex : 1er)
- **Indice** — Place le texte en indice (ex : H₂O)

### Titres

- **Titre 2** — Titre de section principal
- **Titre 3** — Sous-titre
- **Titre 4** — Petit titre

:::tip[Accessibilité]
Respectez la hiérarchie des titres pour une meilleure accessibilité : utilisez le Titre 2 pour les grandes sections, le Titre 3 pour les sous-sections, et le Titre 4 pour les subdivisions. Ne sautez pas de niveau (par exemple, ne passez pas directement du Titre 2 au Titre 4).
:::

### Listes

- **Liste à puces** — Crée une liste non ordonnée
- **Liste numérotée** — Crée une liste ordonnée (1, 2, 3…)
- **Liste de tâches** — Crée une liste avec des cases à cocher

### Blocs

- **Citation** — Insère un bloc de citation mis en retrait
- **Ligne horizontale** — Insère une ligne de séparation entre deux sections
- **Encart info** — Insère un bloc d'information coloré avec un type au choix :

| Type | Couleur | Usage |
|------|---------|-------|
| Info | Bleu | Information générale |
| Attention | Ambre | Avertissement |
| Succès | Vert | Confirmation, bonne pratique |
| Danger | Rouge | Alerte, erreur |

Vous pouvez changer le type d'un encart à tout moment via le menu déroulant situé dans le bloc.

### Alignement

- **Aligner à gauche** — Aligne le texte à gauche (par défaut)
- **Centrer** — Centre le texte
- **Aligner à droite** — Aligne le texte à droite

### Couleur et surlignage

Le bouton **Couleur du texte** propose 7 couleurs :

- Par défaut, Rouge, Orange, Vert, Bleu, Violet, Gris

Le bouton **Surligner** propose 7 couleurs de fond :

- Aucun, Jaune, Vert, Bleu, Rose, Orange, Violet

Sélectionnez le texte concerné, puis cliquez sur la couleur souhaitée. Choisissez « Par défaut » ou « Aucun » pour réinitialiser.

### Typographie

Le bouton **Typographie** ouvre un panneau avec quatre réglages :

- **Taille du texte** — Par défaut, 14px, 16px, 18px, 20px, 24px
- **Interligne** — Par défaut, 1.2, 1.5, 1.8, 2.0
- **Espacement des lettres** — Normal, Large (0.05em), Plus large (0.1em)
- **Lettrine** — Agrandit la première lettre du paragraphe

## Insérer des médias

### Images

1. Cliquez sur le bouton **Image** dans la barre d'outils
2. Le sélecteur de médias s'ouvre : choisissez une image existante ou importez-en une nouvelle
3. L'image est insérée dans l'éditeur

Une fois l'image insérée, cliquez dessus pour afficher les contrôles :

- **Alignement** — Aligner à gauche, Centrer, Aligner à droite ou Pleine largeur
- **Redimensionnement** — Faites glisser la poignée en bas à droite de l'image
- **Légende** — Cliquez sous l'image pour ajouter une légende

:::tip[Médiathèque]
Organisez vos images dans la [Médiathèque](/contenu/mediatheque) avant de les insérer. Cela facilite la recherche et la réutilisation.
:::

### Vidéos

1. Cliquez sur le bouton **Vidéo** dans la barre d'outils
2. Collez l'URL de la vidéo dans le champ
3. Cliquez sur **Intégrer**

:::note[Plateformes supportées]
L'éditeur prend en charge les vidéos **YouTube** et **Dailymotion**. Collez directement le lien de la page de la vidéo (par exemple `https://www.youtube.com/watch?v=...` ou `https://www.dailymotion.com/video/...`).
:::

### Tableaux

1. Cliquez sur le bouton **Tableau** dans la barre d'outils
2. Un tableau de 3 colonnes × 3 lignes est inséré avec une ligne d'en-tête

Une barre de contrôle apparaît au-dessus du tableau sélectionné :

- **Ajouter une colonne** — Ajoute une colonne après la colonne courante
- **Supprimer la colonne** — Supprime la colonne courante
- **Ajouter une ligne** — Ajoute une ligne après la ligne courante
- **Supprimer la ligne** — Supprime la ligne courante
- **En-tête de ligne** — Active ou désactive le style d'en-tête
- **Supprimer le tableau** — Supprime le tableau entier

## Liens

### URL externe

1. Sélectionnez le texte à transformer en lien
2. Cliquez sur le bouton **Lien** dans la barre d'outils
3. Dans l'onglet **URL externe**, collez l'adresse web
4. Appuyez sur **Entrée** pour confirmer

### Lien interne

1. Sélectionnez le texte à transformer en lien
2. Cliquez sur le bouton **Lien**
3. Basculez sur l'onglet **Lien interne**
4. Choisissez le type de contenu : **Pages** ou **Articles**
5. Recherchez le contenu souhaité dans la barre de recherche
6. Cliquez sur le résultat pour créer le lien

:::tip[Préférez les liens internes]
Pour les liens vers d'autres pages de votre site, utilisez toujours l'onglet **Lien interne**. Les URLs seront automatiquement mises à jour si le slug de la page change.
:::

Pour retirer un lien, cliquez dessus puis sur **Supprimer le lien** en bas du dialogue.

## Bouton CTA

Un bouton d'appel à l'action (CTA) permet de mettre en avant un lien important.

1. Cliquez sur le bouton **Bouton CTA** dans la barre d'outils
2. Saisissez le **Texte du bouton** (par exemple « En savoir plus »)
3. Saisissez l'**URL de destination**
4. Cliquez sur **Insérer**

## Commandes slash

Tapez `/` en début de ligne pour ouvrir le menu de commandes rapides. C'est un raccourci pour accéder à la plupart des fonctionnalités sans quitter le clavier.

| Commande | Description |
|----------|-------------|
| Titre 2 | Titre de section |
| Titre 3 | Sous-titre |
| Titre 4 | Petit titre |
| Image | Insérer une image |
| Vidéo | Intégrer une vidéo |
| Tableau | Insérer un tableau |
| Citation | Bloc de citation |
| Séparateur | Ligne horizontale |
| Liste de tâches | Checklist avec cases à cocher |
| Encart info | Bloc d'information coloré |
| Bouton CTA | Bouton d'appel à l'action |

Naviguez dans la liste avec les **flèches haut/bas**, confirmez avec **Entrée** et fermez avec **Échap**.

## Menu contextuel de sélection

Lorsque vous sélectionnez du texte dans l'éditeur complet, une bulle flottante apparaît avec quatre boutons de mise en forme rapide :

- **Gras**
- **Italique**
- **Souligné**
- **Lien**

Ce menu vous permet d'appliquer une mise en forme sans revenir à la barre d'outils.

## Modèles de contenu

Les modèles vous permettent d'insérer des structures de mise en page prêtes à l'emploi.

1. Cliquez sur le bouton **Modèles de contenu** dans la barre d'outils
2. Choisissez un modèle dans la liste
3. Le contenu est inséré à la position du curseur

| Modèle | Description |
|--------|-------------|
| 2 colonnes | Deux colonnes de contenu égales |
| 3 colonnes | Trois colonnes de contenu égales |
| Carte + texte | Image à gauche, texte à droite |
| Section info | Titre, description et deux détails en colonnes |
| Tableau horaires | Tableau des jours et horaires d'ouverture |
| Chiffres clés | Statistiques en trois colonnes avec chiffres en grand |

:::tip[Combinez les modèles]
Vous pouvez insérer plusieurs modèles les uns à la suite des autres pour construire une page complète. Modifiez librement le contenu de chaque bloc après insertion.
:::

## Blocs réutilisables

Les blocs réutilisables vous permettent de sauvegarder du contenu fréquemment utilisé et de l'insérer en un clic dans n'importe quel éditeur.

### Insérer un bloc

1. Cliquez sur le bouton **Blocs réutilisables** dans la barre d'outils
2. Dans l'onglet **Insérer un bloc**, recherchez par nom ou filtrez par catégorie
3. Cliquez sur le bloc souhaité pour l'insérer

### Sauvegarder un bloc

1. Cliquez sur le bouton **Blocs réutilisables**
2. Basculez sur l'onglet **Sauvegarder comme bloc**
3. Saisissez un **Nom du bloc**
4. Choisissez une **Catégorie** : En-tête, Contenu, CTA, Barre latérale, Pied de page ou Autre
5. Cliquez sur **Sauvegarder**

:::note[Contenu sauvegardé]
Si du texte est sélectionné dans l'éditeur, seule la sélection est sauvegardée. Sinon, c'est l'intégralité du contenu de l'éditeur qui est enregistrée comme bloc.
:::

## Sauvegarde automatique

L'éditeur complet enregistre automatiquement un brouillon local toutes les 30 secondes. Si vous quittez la page sans sauvegarder, votre travail est conservé.

Lorsque vous revenez sur le formulaire, une bannière s'affiche :

> Un brouillon non sauvegardé a été trouvé.

Deux options :

- **Restaurer** — Récupère le contenu du brouillon
- **Ignorer** — Supprime le brouillon et conserve le contenu actuel

:::caution[Brouillon local uniquement]
Le brouillon est stocké dans votre navigateur. Il n'est pas partagé entre appareils ni entre navigateurs différents. Les brouillons sont conservés pendant 7 jours maximum.
:::

## Compteur de mots

En bas de l'éditeur complet, un compteur affiche en temps réel le nombre de **mots** et de **caractères** du contenu.

## Raccourcis clavier

| Raccourci | Action |
|-----------|--------|
| Ctrl+B | Gras |
| Ctrl+I | Italique |
| Ctrl+U | Souligné |
| Ctrl+Z | Annuler |
| Ctrl+Maj+Z | Rétablir |
| `/` | Ouvrir les commandes slash |
| Entrée | Confirmer la commande sélectionnée |
| Échap | Fermer le menu de commandes |

:::note[Mac]
Sur Mac, remplacez **Ctrl** par **Cmd** (⌘) pour tous les raccourcis.
:::
