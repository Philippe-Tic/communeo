## Liste des associations

Les associations sont affichées sous forme de **cartes** dans une grille responsive (une colonne sur mobile, deux sur tablette, trois sur ordinateur).

Chaque carte présente :

- Un **badge de catégorie** coloré
- Un **badge de statut** (En attente, Publiée, Rejetée)
- Le **logo** de l'association (si renseigné)
- Le **nom** de l'association
- L'**email de contact** (si renseigné)
- La **source de soumission** : nom du citoyen ayant proposé l'association (si soumission publique)
- La **date de création**

Un **menu contextuel** (icône ···) sur chaque carte propose :

- **Voir** — Afficher la page de détail
- **Modifier** — Ouvrir le formulaire d'édition
- **Supprimer** — Supprimer l'association

### Filtrer

Trois contrôles vous permettent d'affiner l'affichage :

- **Recherche** — Filtrer par nom d'association
- **Catégorie** — Sport, Culture, Social, Environnement, Éducation ou Autre
- **Statut** — En attente, Publiée ou Rejetée

:::tip[Astuce]
Filtrez par statut "En attente" pour traiter rapidement les nouvelles propositions soumises par les citoyens.
:::

## Catégories

Six catégories sont disponibles, chacune associée à une couleur :

- **Sport** (bleu)
- **Culture** (violet)
- **Social** (rose)
- **Environnement** (vert)
- **Éducation** (jaune)
- **Autre** (gris)

## Créer une association

1. Cliquez sur le bouton **Nouvelle association** en haut de la liste
2. Remplissez le formulaire (voir les sections ci-dessous)
3. Cliquez sur **Créer**

Les associations créées manuellement depuis l'administration sont automatiquement publiées.

### Informations générales

- **Nom de l'association** (obligatoire) — Le nom officiel de l'association
- **Catégorie** (obligatoire) — La catégorie de l'association (Sport, Culture, Social, Environnement, Éducation ou Autre)
- **Description** — Un texte de présentation de l'association

### Contact

- **Personne de contact** — Nom du responsable ou référent
- **Email de contact** — Adresse email de l'association
- **Téléphone** — Numéro de téléphone
- **Site web** — URL du site internet de l'association
- **Adresse** — Adresse postale du siège

### Logo

- **Logo** — Image représentant l'association (format image)

## Modifier une association

Deux chemins possibles :

- Depuis la liste : cliquez sur le menu ··· d'une carte, puis sur **Modifier**
- Depuis la page de détail : cliquez sur le bouton **Modifier**

Le formulaire s'affiche avec les données existantes. Effectuez vos modifications, puis cliquez sur **Mettre à jour**.

## Voir le détail

Pour accéder au détail d'une association :

- Cliquez directement sur une carte dans la liste
- Ou cliquez sur le menu ··· → **Voir**

La page de détail affiche :

- Les **badges** de catégorie, de statut, et éventuellement "Soumission publique"
- Le **logo** (si renseigné)
- La **description** (si renseignée)
- Les **coordonnées** : personne de contact, email (lien cliquable), téléphone, site web (lien cliquable), adresse
- Les **métadonnées** : dates de création, modification et éventuelle date de modération

Les boutons d'action en haut de la page permettent de :

- **Retour** — Revenir à la liste
- **Modifier** — Ouvrir le formulaire d'édition
- **Supprimer** — Supprimer l'association

## Modérer les soumissions publiques

Les citoyens peuvent proposer des associations via le formulaire public du site. Ces propositions apparaissent dans la liste avec le statut **En attente** et un badge **Soumission publique**.

:::note[Bon à savoir]
Les soumissions publiques affichent les coordonnées du citoyen ayant proposé l'association (nom et email) dans un encadré dédié sur la page de détail.
:::

### Approuver ou rejeter

Sur la page de détail d'une association en attente, deux boutons de modération sont disponibles :

- **Approuver** (vert) — Publie l'association sur le site
- **Rejeter** (rouge) — Refuse la proposition

La date de modération est automatiquement enregistrée lors de l'approbation ou du rejet.

## Supprimer une association

Deux chemins possibles :

- Depuis la liste : cliquez sur le menu ··· → **Supprimer**
- Depuis la page de détail : cliquez sur le bouton **Supprimer**

Un dialogue de confirmation s'affiche avec le nom de l'association et le message "Cette action est irréversible." Cliquez sur **Supprimer** pour confirmer ou **Annuler** pour revenir en arrière.

:::caution[Attention]
La suppression est définitive. Toutes les données de l'association (logo, coordonnées, métadonnées) seront perdues.
:::
