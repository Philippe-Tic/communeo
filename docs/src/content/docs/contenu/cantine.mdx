La cantine scolaire vous permet de publier les menus de la semaine sur le site de votre commune. Deux modes de saisie sont disponibles : upload d'une image ou d'un PDF, ou saisie manuelle des repas jour par jour. Cette page vous guide dans la gestion de ces menus.

## Navigation par semaine

La page affiche le menu d'une semaine à la fois. Une barre de navigation en haut permet de :

- Cliquer sur **◀** pour afficher la semaine précédente
- Cliquer sur **▶** pour afficher la semaine suivante
- Cliquer sur **Aujourd'hui** pour revenir à la semaine en cours

La période affichée est indiquée au format "Lundi — Dimanche" (dates complètes).

## Consulter un menu

Si un menu existe pour la semaine affichée, il est présenté sous forme de carte avec :

- Une icône indiquant le **mode de saisie** (image ou saisie manuelle)
- Le **nom de l'école** (si renseigné)
- Les boutons **Modifier** et **Supprimer**

### Mode image

L'image du menu est affichée directement. Si un fichier PDF est associé, un lien **Télécharger le PDF** est disponible.

### Mode saisie manuelle

Un **tableau** affiche les repas de la semaine avec les colonnes suivantes :

| Jour | Entrée | Plat | Accomp. | Fromage | Dessert | Goûter | Labels |

Les repas du lundi au vendredi sont listés ligne par ligne. Les **étiquettes qualité** sont affichées sous forme de badges colorés avec emoji :

- 🌱 **Bio** (vert)
- 📍 **Local** (bleu)
- 🥬 **Végétarien** (émeraude)
- 👨‍🍳 **Fait maison** (orange)
- 🏅 **AOP** (jaune)

## Créer un menu

1. Si aucun menu n'existe pour la semaine affichée, cliquez sur **Créer le menu de la semaine** (ou sur **Créer le menu** dans l'en-tête)
2. Remplissez le formulaire (voir les sections ci-dessous)
3. Cliquez sur **Créer**

### Informations générales

- **Semaine du** (obligatoire) — La date est automatiquement ajustée au lundi de la semaine sélectionnée
- **Nom de l'école** — Texte libre (200 caractères max., ex : "École Jean Moulin"). Utile si votre commune a plusieurs établissements.

### Mode de saisie

Deux options s'excluent mutuellement :

1. **Image / PDF** — Uploadez une photo ou un PDF du menu
2. **Saisie manuelle** — Saisissez les repas jour par jour

#### Mode image

- **Image du menu** — Fichier image (JPG, PNG, etc.)
- **PDF du menu** — Fichier PDF (optionnel), téléchargeable par les citoyens

:::tip[Astuce]
Le mode image est idéal si vous recevez le menu au format PDF ou photo de la part du prestataire de restauration.
:::

#### Mode saisie manuelle

Un formulaire par jour (du lundi au vendredi) avec les champs suivants :

- **Entrée** — Le plat d'entrée
- **Plat principal** (obligatoire) — Le plat principal du repas
- **Accompagnement** — La garniture ou l'accompagnement
- **Fromage** — Le fromage ou le produit laitier
- **Dessert** — Le dessert
- **Goûter** — Le goûter de l'après-midi
- **Labels qualité** — Cliquez sur les badges pour activer ou désactiver les étiquettes : Bio, Local, Végétarien, Fait maison, AOP

:::note[Bon à savoir]
Les labels qualité sont des badges cliquables. Un badge actif est affiché en pleine opacité, un badge inactif est atténué. Cliquez dessus pour basculer l'état.
:::

## Modifier un menu

Depuis la vue du menu de la semaine, cliquez sur le bouton **Modifier**. Le formulaire s'affiche avec les données existantes. Effectuez vos modifications, puis cliquez sur **Modifier**.

## Supprimer un menu

Depuis la vue du menu de la semaine, cliquez sur le bouton **Supprimer**.

Un dialogue de confirmation s'affiche. Cliquez sur **Supprimer** pour confirmer ou **Annuler** pour revenir en arrière.

:::caution[Attention]
La suppression est définitive. Le menu et tous ses fichiers (image, PDF) seront perdus.
:::
