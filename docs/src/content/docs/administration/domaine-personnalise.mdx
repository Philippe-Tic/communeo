---
title: Domaine personnalisé
description: Configurer un nom de domaine personnalisé pour votre site municipal en trois étapes.
---

Par défaut, votre site est accessible via une adresse Netlify (ex : `lyon-mairie.netlify.app`). La configuration d'un domaine personnalisé vous permet d'utiliser votre propre adresse (ex : `www.mairie-lyon.fr`).

## Vue d'ensemble

La configuration se déroule en trois étapes, représentées par un indicateur de progression en haut de la page :

1. **Saisie du domaine** — Vous indiquez le nom de domaine souhaité
2. **Pointage DNS** — Vous configurez les enregistrements DNS chez votre fournisseur
3. **Domaine actif** — Le domaine est vérifié et votre site est accessible sur la nouvelle adresse

Chaque étape est marquée par un cercle numéroté : vert lorsqu'elle est terminée, bleu pour l'étape en cours et gris pour les étapes à venir.

## Étape 1 : Saisir votre nom de domaine

1. Dans le champ **Nom de domaine**, saisissez votre domaine (ex : `mairie-lyon.fr` ou `mairie.lyon.fr`)
2. Cliquez sur **Configurer**

Le système nettoie automatiquement la saisie (suppression du `http://`, `https://` ou `www.` en début de chaîne).

:::note[Vous n'avez pas encore de nom de domaine ?]
Vous pouvez acheter un nom de domaine chez un fournisseur (registrar) comme OVH, Gandi ou Ionos. Une fois le domaine acheté, revenez ici pour le configurer.
:::

## Étape 2 : Configurer le pointage DNS

Une fois le domaine saisi, une bannière orange **Pointage DNS requis** s'affiche. Vous devez maintenant configurer vos enregistrements DNS chez votre fournisseur de domaine.

### Pour un domaine racine

Si vous utilisez un domaine racine (ex : `mairie-lyon.fr`), deux enregistrements sont nécessaires :

| Type | Nom / Hôte | Valeur | But |
|------|-----------|--------|-----|
| **A** | `@` ou vide | Adresse IP fournie | Pointe le domaine vers le serveur |
| **CNAME** | `www` | Adresse fournie | Redirige `www.mairie-lyon.fr` vers le site |

Chaque valeur dispose d'un bouton de copie pour faciliter la saisie dans l'interface de votre fournisseur.

:::tip[Enregistrement A vs CNAME]
Les domaines racines (comme `mairie-lyon.fr`) ne supportent pas les CNAME selon les standards DNS. On utilise donc un **enregistrement A** pour pointer le domaine vers le serveur. Le **CNAME www** permet aux visiteurs qui tapent `www.mairie-lyon.fr` d'arriver aussi sur votre site. Chez certains fournisseurs, pour le nom de l'enregistrement A, saisissez `@` ou laissez le champ vide.
:::

### Pour un sous-domaine

Si vous utilisez un sous-domaine (ex : `mairie.lyon.fr`), un seul enregistrement CNAME suffit :

| Type | Nom / Hôte | Valeur | But |
|------|-----------|--------|-----|
| **CNAME** | `mairie` | Adresse fournie | Pointe le sous-domaine vers le site |

### Vérifier le pointage

Une fois les enregistrements DNS configurés chez votre fournisseur :

1. Revenez sur cette page
2. Cliquez sur le bouton **Vérifier le pointage DNS**

:::note[Délai de propagation]
La propagation des enregistrements DNS peut prendre jusqu'à 48 heures. Si la vérification échoue juste après la configuration, c'est normal. Vous pouvez revenir vérifier plus tard.
:::

## Étape 3 : Domaine actif

Lorsque la vérification réussit, une alerte verte **Domaine actif** confirme que votre site est accessible sur votre domaine personnalisé. La page affiche :

- **Domaine** — Votre nom de domaine avec un lien direct vers le site
- **SSL** — Le certificat de sécurité est activé automatiquement
- **Configuré le** — La date de mise en place du domaine

## Supprimer un domaine personnalisé

Si vous souhaitez revenir à l'adresse Netlify par défaut :

1. Cliquez sur **Supprimer le domaine**
2. Confirmez la suppression dans la boîte de dialogue

:::caution[Retour à l'URL par défaut]
La suppression du domaine personnalisé est immédiate. Votre site redeviendra accessible uniquement via son adresse Netlify par défaut.
:::

## En cas d'erreur

Si la vérification du domaine échoue, une alerte rouge **Erreur de configuration** s'affiche. Deux options s'offrent à vous :

- **Réessayer la vérification** — Relancez la vérification après avoir corrigé vos enregistrements DNS ou attendu la propagation
- **Supprimer et recommencer** — Supprimez le domaine et reprenez la configuration depuis l'étape 1
