Pour gérer le site de votre commune, vous devez d'abord accéder à l'espace d'administration. Cette page vous explique comment vous connecter et vous repérer dans l'interface.

## Se connecter

1. Ouvrez votre navigateur et rendez-vous sur l'adresse de votre espace d'administration (communiquée par votre responsable informatique)
2. Saisissez votre **adresse email** dans le champ "Email"
3. Saisissez votre **mot de passe** dans le champ "Mot de passe"
4. Cliquez sur le bouton **Se connecter**

Vous êtes redirigé vers le [tableau de bord](/contenu/tableau-de-bord).

:::note[En cas d'erreur]
Si vos identifiants sont incorrects, un message d'erreur s'affiche en haut du formulaire. Vérifiez votre adresse email et votre mot de passe, puis réessayez. Le mot de passe doit contenir au moins 6 caractères.
:::

## Mot de passe oublié

Si vous avez oublié votre mot de passe :

1. Sur la page de connexion, cliquez sur **Mot de passe oublié ?**
2. Saisissez votre adresse email
3. Cliquez sur **Envoyer le lien**
4. Consultez votre boîte de réception : vous recevrez un email contenant un lien de réinitialisation
5. Cliquez sur le lien dans l'email
6. Choisissez un nouveau mot de passe et confirmez-le
7. Cliquez sur **Réinitialiser**

Vous pouvez ensuite vous connecter avec votre nouveau mot de passe.

## Première connexion (invitation)

Si un administrateur vous a créé un compte, vous recevez un **email d'invitation** :

1. Ouvrez l'email et cliquez sur le lien d'activation
2. Sur la page "Activer votre compte", définissez votre mot de passe (6 caractères minimum)
3. Confirmez votre mot de passe dans le second champ
4. Cliquez sur **Activer mon compte**

Un message de confirmation s'affiche. Vous pouvez ensuite vous connecter avec votre adresse email et le mot de passe que vous venez de choisir.

## Naviguer dans l'interface

L'interface d'administration se compose de trois zones principales : l'en-tête, la barre latérale et la zone de contenu.

### L'en-tête

La barre horizontale en haut de l'écran contient :

- **Le logo Communeo** — Cliquez dessus pour revenir au tableau de bord
- **Le nom de votre commune** — Affiché à droite du logo (visible sur grand écran)
- **Le bouton de thème** — Permet de basculer entre le mode clair et le mode sombre (voir plus bas)
- **Votre menu utilisateur** — Affiche vos initiales et votre nom. En cliquant dessus, vous accédez à :
  - Votre adresse email
  - Un lien vers le site en ligne de votre commune
  - **Mon profil** — Pour modifier vos informations personnelles
  - **Déconnexion** — Pour quitter l'espace d'administration

### La barre latérale

Sur la gauche de l'écran, la barre latérale regroupe toutes les sections du site. Elle est organisée en trois groupes dépliables :

- **Contenu** — Actualités, Pages, Événements, Documents, Alertes, Collecte des déchets, Cantine, Médiathèque
- **Communauté** — Messages, Équipe municipale, Associations, Newsletter
- **Paramètres** — Configuration du site, Conformité légale, Déploiement, Domaines, Utilisateurs

Le lien **Tableau de bord** est toujours visible en haut de la barre latérale, au-dessus des groupes.

La section dans laquelle vous vous trouvez est mise en évidence par une couleur de fond différente.

### Navigation sur mobile

Sur téléphone ou tablette, la barre latérale est masquée pour laisser plus de place au contenu.

1. Appuyez sur le bouton **menu** (icône ☰) en haut à gauche de l'écran
2. Un panneau latéral s'ouvre avec la même navigation que sur ordinateur
3. Sélectionnez la section souhaitée : le panneau se referme automatiquement

## Mode sombre / clair

L'interface propose deux thèmes d'affichage :

- **Mode clair** — Fond blanc, texte sombre (par défaut)
- **Mode sombre** — Fond sombre, texte clair (plus confortable en faible luminosité)

Pour changer de thème, cliquez sur l'icône **Lune** (pour passer en mode sombre) ou **Soleil** (pour revenir en mode clair) dans l'en-tête.

Votre préférence est mémorisée : lors de votre prochaine connexion, le thème choisi sera automatiquement appliqué.

:::tip[Astuce]
Ajoutez la page de connexion à vos **favoris** (ou marque-pages) pour y accéder rapidement.
:::
