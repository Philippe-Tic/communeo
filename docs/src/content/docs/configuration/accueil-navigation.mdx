La page d'accueil de votre site est entièrement modulable : chaque section peut être activée ou désactivée individuellement. L'éditeur de navigation vous permet de construire le menu principal du site. Cette page couvre les onglets **Page d'accueil** et **Navigation**.

Pour y accéder, rendez-vous dans **Paramètres > Configuration du site**, puis cliquez sur l'onglet **Page d'accueil** ou **Navigation**.

## Page d'accueil

L'onglet **Page d'accueil** regroupe toutes les sections de votre page d'accueil. Chaque section dispose d'un toggle **Afficher** pour l'activer ou la désactiver.

### Hero

La bannière principale affichée en haut de la page d'accueil.

- **Titre Hero** (max 120 caractères) — Le titre principal affiché sur la bannière
- **Sous-titre** — Un texte complémentaire affiché sous le titre
- **Image de fond** — L'image affichée en arrière-plan de la bannière (sélecteur d'image)
- **Bouton principal (CTA)** — Libellé (max 50 caractères) et URL du bouton d'action principal
- **Bouton secondaire (CTA)** — Libellé (max 50 caractères) et URL du bouton d'action secondaire

### Contenu éditorial

Un espace de contenu libre affiché sur la page d'accueil, sous les accès rapides.

- **Contenu** — Un champ en [texte riche](/reference/editeur-texte/) (variante complète) pour rédiger du contenu libre
- **Meta description SEO** (max 160 caractères) — Le texte affiché dans les résultats des moteurs de recherche. Un compteur de caractères est affiché sous le champ.

:::tip[SEO]
Rédigez une meta description claire et concise, entre 150 et 160 caractères. Elle doit donner envie de cliquer tout en résumant le contenu de votre page d'accueil.
:::

### Accès rapides

Liens rapides affichés sous le hero, sous forme de cartes avec icône.

- **Afficher** — Toggle on/off

Lorsque la section est activée, un tableau dynamique permet de configurer chaque lien :

- **Libellé** (max 50 caractères) — Le texte du lien
- **URL** — La destination du lien (ex : `/demarches`)
- **Icône** — Choisie parmi 16 icônes disponibles : Document, Identité, Dossier, Courrier, Alerte, Horloge, Téléphone, Carte, Calendrier, Personnes, Bâtiment, Cœur, Information, Bouclier, Livre, Globe
- **Description** (optionnel, max 100 caractères) — Un texte complémentaire affiché sous le libellé

Cliquez sur **Ajouter un lien rapide** pour ajouter une ligne, ou sur l'icône **corbeille** pour en supprimer une.

:::note[Liens par défaut]
Si aucun accès rapide n'est configuré, des liens par défaut seront utilisés automatiquement.
:::

### Mot du Maire

Un encart dédié au mot du maire, avec sa photo affichée automatiquement.

- **Afficher** — Toggle on/off
- **Titre de la section** (max 120 caractères) — Le titre affiché au-dessus du contenu (ex : "Le mot du Maire")
- **Contenu** — Un champ en [texte riche](/reference/editeur-texte/) pour le texte du maire

:::note[Photo automatique]
La photo du maire est automatiquement récupérée depuis les membres de l'[équipe municipale](/communaute/equipe/) ayant le rôle "Maire". Il n'est pas nécessaire de la renseigner ici.
:::

### Actualités

Affiche les dernières actualités publiées sur la page d'accueil.

- **Afficher** — Toggle on/off
- **Nombre d'articles affichés** (1 à 6) — Le nombre d'articles mis en avant sur la page d'accueil

### Événements

Affiche les prochains événements sur la page d'accueil.

- **Afficher** — Toggle on/off
- **Nombre d'événements affichés** (1 à 6) — Le nombre de prochains événements affichés

### Chiffres clés

Affiche des statistiques ou données clés de votre commune sous forme de cartes.

- **Afficher** — Toggle on/off

Lorsque la section est activée, un tableau dynamique permet de configurer chaque chiffre :

- **Valeur** (max 20 caractères) — Le chiffre ou la donnée (ex : "12 500")
- **Label** (max 60 caractères) — La légende du chiffre (ex : "Habitants")
- **Icône** — Choisie parmi 10 icônes disponibles : Personnes, Carte, Bâtiment, Calendrier, Cœur, Livre, Globe, Bouclier, Arbre, Étoile

Cliquez sur **Ajouter un chiffre clé** pour ajouter une ligne, ou sur l'icône **corbeille** pour en supprimer une.

### Associations

Affiche les associations publiées de votre commune sur la page d'accueil.

- **Afficher** — Toggle on/off
- **Nombre d'associations affichées** (1 à 12) — Le nombre d'associations affichées

### Partenaires

Affiche les logos et liens de vos partenaires institutionnels ou associatifs.

- **Afficher** — Toggle on/off

Lorsque la section est activée, un tableau dynamique permet de configurer chaque partenaire :

- **Nom du partenaire** (max 100 caractères) — Le nom affiché
- **URL du site web** — Le lien vers le site du partenaire
- **Logo** — L'image du partenaire (sélecteur d'image)

Cliquez sur **Ajouter un partenaire** pour ajouter une ligne, ou sur l'icône **corbeille** pour en supprimer une.

### Météo locale

Affiche un widget météo en temps réel sur la page d'accueil, alimenté par les données Open-Meteo.

- **Afficher** — Toggle on/off

:::caution[Coordonnées GPS requises]
Les coordonnées GPS (latitude et longitude) doivent être renseignées dans l'onglet **Infos pratiques** pour que le widget météo fonctionne. Voir [Informations générales — Infos pratiques](/configuration/informations-generales/#population-et-coordonnées-gps).
:::

### Collecte des déchets

Affiche les prochaines collectes de déchets sur la page d'accueil.

- **Afficher** — Toggle on/off

Les données proviennent du module [Collecte des déchets](/contenu/collecte-dechets/).

### Perturbations en cours

Affiche les perturbations en cours (travaux, coupures, déviations) sur la page d'accueil.

- **Afficher** — Toggle on/off

Les données proviennent du module [Alertes](/contenu/alertes/).

### Cantine scolaire

Affiche le menu de cantine de la semaine sur la page d'accueil.

- **Afficher** — Toggle on/off

Les données proviennent du module [Cantine](/contenu/cantine/).

### Newsletter

Affiche un formulaire d'inscription à la newsletter sur la page d'accueil et dans le pied de page.

- **Afficher** — Toggle on/off

Les inscriptions sont gérées dans le module [Newsletter](/communaute/newsletter/).

### Principes

L'éditeur de navigation est un éditeur hiérarchique qui permet de construire le menu principal. Il prend en charge trois types d'éléments :

- **Liens prédéfinis** — Des pages fonctionnelles intégrées à Communeo (Actualités, Événements, Documents, etc.)
- **Pages** — Les pages publiées que vous avez créées dans le module [Pages](/contenu/pages/)
- **Sections** — Des sous-menus regroupant d'autres éléments (liens ou pages)

Chaque élément peut être **activé ou désactivé** individuellement avec un toggle, sans être supprimé.

### Ajouter des éléments

Trois boutons en bas de l'éditeur permettent d'ajouter des éléments :

**Ajouter un lien prédéfini :**

1. Cliquez sur **Ajouter un lien**
2. Sélectionnez le lien souhaité dans la liste déroulante

Les 10 liens prédéfinis disponibles sont : Actualités, Événements, Documents, Équipe municipale, Associations, Démarches, Open Data, Collecte des déchets, Perturbations, Cantine scolaire. Chaque lien ne peut être ajouté qu'une seule fois.

**Ajouter une page :**

1. Cliquez sur **Ajouter une page**
2. Sélectionnez la page publiée dans la liste déroulante
3. Si des sections existent, choisissez de placer la page **au niveau principal** ou **dans une section** spécifique

**Ajouter une section (sous-menu) :**

1. Cliquez sur **Ajouter une section**
2. Saisissez le nom de la section dans le champ qui apparaît
3. Cliquez sur **Ajouter** pour confirmer (ou **Annuler**)

### Réordonner les éléments

L'éditeur supporte le **glisser-déposer** (drag-and-drop) :

- Glissez un élément vers le haut ou le bas pour changer sa position
- Les éléments à l'intérieur d'une section peuvent également être réordonnés par glisser-déposer
- Le menu contextuel de chaque élément permet de **déplacer un élément dans une section** ou de **remonter un enfant au niveau principal**

### Supprimer et désactiver

- **Supprimer** — Cliquez sur l'icône **corbeille** d'un élément pour le retirer définitivement du menu
- **Désactiver** — Utilisez le toggle de chaque élément pour le masquer temporairement sans le supprimer

:::caution[Sections vides]
Une section sans enfant est signalée par un avertissement en rouge. Ajoutez-y des éléments ou supprimez-la pour éviter un sous-menu vide sur votre site.
:::

### Réinitialiser

Le bouton **Réinitialiser** (en bas à droite) restaure la configuration de navigation par défaut, composée de l'ensemble des 10 liens prédéfinis. Cette action remplace toute la configuration actuelle.
